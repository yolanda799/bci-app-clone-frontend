# BCI App Front-End Clone

Front-end clone project of the BCI mobile application interface, developed for study and practice purposes.  
Built using **HTML5** and **CSS3**, focusing on layout, responsiveness, and visual component organization.  
This project has no real functionality and is not affiliated with BCI.

## Features
- Responsive design
- HTML5 structure
- Styled with CSS3
- Educational project for practice purposes
